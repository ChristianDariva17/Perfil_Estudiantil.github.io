El problema que aborda

Las señales públicas y las fuentes oficiales de contenido suelen estar distribuidas entre reproductores, listas y páginas diferentes. Canales Abiertos propone una entrada única para explorarlas.

El proyecto combina descubrimiento, filtrado y reproducción sin presentar el catálogo como contenido propio: los enlaces apuntan a fuentes públicas u oficiales.

Qué se puede verificar

01

Señales

El proyecto documenta canales públicos y regionales con reproducción HLS o enlaces directos.

02

Catálogo

Incluye fuentes oficiales de cine en español, con filtros por nombre, región o temática.

03

Interfaz

La demo publica búsqueda, filtros, reproductor y una interfaz responsive de tema oscuro.

Decisiones técnicas visibles

  • hls.js se utiliza como soporte para reproducir streams HLS cuando el navegador lo requiere.
  • Una lista M3U unificada organiza parte de las fuentes de canales públicos.
  • La carpeta `dist/` contiene el sitio estático que se sirve en GitHub Pages.

La disponibilidad de una señal puede cambiar por región, programación o derechos. La propia interfaz comunica esa limitación y remite a las fuentes oficiales.
